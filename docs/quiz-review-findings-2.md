## 3. 表示の要確認

`$$` なしで数式環境を直接書いているもの。アプリのレンダラーで表示されるか確認すること。

- `\begin{align*}`：#331, #314
- `\begin{align}`（* なし）：#315 → 式番号 (1)(2)… が付く
- `\[ \begin{aligned} ... \]`：#298
- `\[ ... \]`（インライン混在）：#238

表示できない場合は、`$$\begin{aligned}...\end{aligned}$$` に正規化することを推奨。

## 5. 修正依頼

### A. コード修正
1. 因数分解の整形で、根が 0 のとき `(x + 0)` ではなく `x` と出力する（#296, #294, #290）
2. ベクトルなす角のパラメータ生成で、正解角度が偏らないようにする

### B. 機械的バリデーションに追加
1. **`$...$` / `$$...$$` の外にある LaTeX コマンドの検出**（`\int` `\vec` `\frac` `\sqrt` `\left` など）→ #306, #334 を検出できる
2. `(x + 0)` `(x - 0)` `+ 0` などの不要項の検出
3. **メタ表現の検出**：「与えられた解き方」「要点に従う」「指示」「プロンプト」など → #305
4. 数式環境（`\begin{align}` 等）が `$$` で囲まれているか。`align`（* なし）は警告
5. 前回依頼分（KaTeX パース、`$` の対応、`$` 内の日本語、度記号チェック等）も引き続き適用

### C. LLM 生成・検証プロンプトへの追加
- 解き方の要点を LLM に渡している場合は、「渡された指示や要点そのものに言及しない」と明記する
- 用語指定：「点と傾きの式（点斜式）」「底の変換公式」「有理化」など正しい用語を使う。「2 点の式」「微分方程式」は使わない
- 検証プロンプトに追加
  - 解説の各行の主張（「正なので」「上側にある」等）と、直後の式が矛盾しないか
  - ヒントが問題の解法と一致しているか（内積の問題で余弦定理を勧めていないか等）
  - 問題文に同語反復や冗長な前置きがないか

### D. 既存データ（ID #266 以降）
- 1 章の ID は修正 or 再生成
- 2 章は再生成、または解説・ヒントだけ再生成
