## 3. 直したこと

1. **資料を 74 個足した**（`catalog.MORE_SOURCES`。130 個 → 204 個）。法令は 60 個で、どれも開発の環境から e-Gov の API で取れることを確かめた（100 字前後の短い条は、ほかの条とまとめた）。足した主なもの：憲法（請願・国家賠償・奴隷的拘束、学問・婚姻、刑事手続、最高法規、任期・会期、予備費など）、民法（公序良俗・錯誤・詐欺、契約の成立・売買）、消費者契約法 8・10 条、製造物責任法、裁判所法、検察審査会法、国会法、内閣法、公職選挙法（定数・期日前投票・選挙運動）、政治資金規正法、政党助成法、地方自治法（直接請求・不信任・住民監査請求など）、独禁法 2・19 条、会社法、環境基本法、財政法・消費税法・国税通則法・地方財政法、日銀法 3・4・15 条、銀行法、預金保険法、労基法（労働条件・解雇予告・休憩休日・36 協定）、労組法 6・7 条、最低賃金法、労働関係調整法、育児・介護休業法、国民年金法、介護保険法、健康保険法、児童福祉法、PKO 協力法、外為法、関税法、障害者差別解消法、教育基本法、男女共同参画社会基本法。条文のない・少ない小単元（思想と倫理・青年期・国際経済・国際政治）には Wikipedia の記事を足した（開発の環境から Wikipedia に入れず確かめていない。見つからなければ飛ばして次の資料へ進む）
2. **使い切った小単元に作りに行き続けない**（worker。科目によらない）。依頼の中で「使い切り」を返した小単元は、その依頼ではもう作りに行かない。範囲の小単元がすべて使い切りなら、すぐに依頼を終え、理由を「選んだ範囲の題材をすべて使い切りました」と出す（前は作り直しの上限まで「使い切り」の行を 6 件ずつ足し、「検証に合格した問題がありませんでした」と出ていた）
3. **条文を先に試すときも、1 回に試す 4 つのうち最後の 1 つは Wikipedia の資料にする**（見つからない条文が続いても進めるように）
