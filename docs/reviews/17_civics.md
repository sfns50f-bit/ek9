## 3. このレビューと一緒に直したこと

1. **資料にある言葉を引いた理由・ヒントを「内部の言葉」として弾かない**（`check.japanese_issues` に資料を渡し、資料にある語は数えない）
2. **差し替えができなかった理由を記録の 1 行目に残す**（「誤答の差し替えはできなかった（…）」「誤答を差し替えても止まった（…）」）。次の書き出しで内訳が分かる
3. **本文に混ざる「【出典】」「【脚注】」などの小見出しとその中身を落とす**（`sources.tidy`。「小選挙区比例代表並立制」の本文に「【出典】 Inter Parliamentary Union…」が入っていた）

## 4. 残っていること（効果が大きい順）

1. **知識だけの事実の判定**（第 16 回 3 章 C）。今回の致命的 3 問はすべてこれでしか止まらない。コードを足す前に、今ある設定で試せる：「状態 → モデルと思考モード」の公共の欄の**「事実の判定のモデル」を `gemma4:26b-a4b-it-qat` か Haiku（API）に変えて**、同じ数だけ作って比べる。e4b に「非常任理事国は連続して再選できないだけ」「首相指名では両院協議会は必ず開く」の知識は期待しにくい
2. **差し替えた誤答の質**（#1683・#1694）。差し替えの指示に「『影響を与える』『関係がある』のような、誤りと言い切れない弱い述語にしない」「意味の通る場面にする」を足す。2. の記録で失敗の内訳を見てから、指示を直すのがよい
3. **長い条文の根拠の文**（地方自治法 74 条で 3 問落ちた）。条文の資料では、根拠を「第◯項」の単位で照らす（項の途中まででも、その項の先頭から一致していれば通す）ことを検討
4. **資料の不正確な文**（安保理の「再任出来ず」）。Wikipedia の記事は節を選べるようにするか、制度の資料は条文・公的機関の文に寄せる。国際政治は国連憲章の条文が e-Gov にないので、資料の候補を決める必要がある
5. 公共の見本集 `golden_set_civics.json`。止めるべき問題の種がそろってきた：第 16 回の 9 問＋今回の #1719・#1721・#1689・#1694
