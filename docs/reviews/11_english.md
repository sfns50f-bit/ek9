## 2. 締めの後の改善候補（急がない）

### 2-1. 「語の直前に a / an がない」の点検を、文中の語の意味の問題から外す

- この点検は、空所に入る語とスペルの問題で「a / an が答えの手がかりになる」のを防ぐためのもの
- 文中の語の意味の問題（`en-vocab-meaning`）では語が見えているので手がかりにならず、作成役が冠詞を消して英文を誤らせる原因になっている（#1215）
- 意味の問題では点検しない。または、a / an の直後の語が母音で始まるかが合っていれば通す

### 2-2. 機械的な点検で落ちる問題を、捨てずに直す

不合格の理由で一番多いのは「英文・選択肢・解説の点検」（30 問）。中身は、コードで直せるものが多い。

| 点検 | 件数の例 | 直し方の案 |
|---|---|---|
| 誤答の種類が「本文に書かれていない」なのに、中心の語が本文にある | #1315, #1309, #1301, #1299, #1298, #1293, #1274, #1271 | 種類は生徒に見せる情報ではないので、不合格にせず「一部だけ合っている」に付け替えるか、記録だけ残す |
| ヒントの「第 N 段落」が根拠の文の段落と違う | #1297, #1296, #1295 | 根拠の文の段落はコードで分かるので、ヒントの番号をコードで直す |
| 解説が選択肢を A・B の記号で呼んでいる | #1312, #1311, #1294, #1293, #1292 | 直しの依頼を 1 回したあとも残る場合、記号の部分を選択肢の文に置き換える（コードで置換できる） |
| 解説が空 | #1287, #1286 | 解説だけを書き直させる（設問全体は捨てない） |

- これで合格率は上がり、作成にかかる時間が減る見込み

### 2-3. 重複による無駄

- 依頼 #158 で、36 問中 23 問が「既存の問題と同じ数値」で落ちた。単語リストの語が使い切られかけている可能性がある
- 作成の前に、使った語を候補から外す。候補が足りなければ依頼の時点で「残りの語が少ない」と知らせる
- 不合格の理由の文言「同じ数値」「数値が正解と違う」は数学の言い回しなので、英語では「同じ語」「答えが正解と違う」にする
